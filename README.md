# Methodddd Selfbot

A ready-to-use JavaScript starter for building a Discord selfbot, powered by `discord.js-selfbot-v13`.

Includes one feature: Rich Presence with an image and four descriptions that rotate every 15 seconds. This is a starter template for further development.

## Setup

Requires Node.js 20.18.0 or newer.

1. Install dependencies:

   ```bash
   npm install
   ```

2. Add your token to `config.json`:

   ```json
   {
     "token": "YOUR_TOKEN_HERE"
   }
   ```

3. Start the application:

   ```bash
   npm start
   ```

No build step is required. Rich Presence settings are included in the source code.

## Notice

Using selfbots is not recommended. They violate Discord's Terms of Service and may result in an account ban.

Keep your token private and never commit it to GitHub.
